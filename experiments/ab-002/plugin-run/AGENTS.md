# Daymark Website Working Rules

- Work only inside this repository.
- Use the dependency-free server already provided.
- Use only local vanilla HTML, CSS, and JavaScript; no external network resources.
- Put implementation files in `public/index.html`, `public/styles.css`, and `public/app.js`.
- Preserve `server.mjs` and its public-file behavior.
- `npm test` is the required verification command.
