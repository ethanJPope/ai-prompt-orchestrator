Build a polished, memorable single-page marketing website for **Daymark**, a calm focus planner for students and independent creators. The audience is 16–25. It should feel premium and editorial—not corporate, childish, or like a generic SaaS template.

Use only vanilla HTML, CSS, and JavaScript with the dependency-free local server already in this project. Do not use external packages, images, fonts, CDNs, or network requests.

Required content and behavior:

- a sticky navigation bar with the Daymark wordmark and a clear call to action;
- a hero using the exact headline **“Make the week feel possible.”**, concise supporting copy, two calls to action, and a convincing product preview;
- a compact outcomes/statistics strip;
- an asymmetric bento-style feature section;
- an interactive weekly focus planner with seven toggleable day controls and a range slider for 1–6 focus hours per selected day;
- the planner must update its weekly total and a short contextual status message live;
- a clear three-step “how it works” section, one testimonial, and a strong final call to action with footer;
- responsive layouts that feel intentionally designed at both 1440px desktop and 390px mobile widths;
- accessible semantic HTML, keyboard-visible focus states, reduced-motion support, and no horizontal page overflow.

Visual direction: deep ink and warm parchment as the base, with electric tangerine and acid mint accents; expressive editorial typography using system fonts; crisp borders, purposeful whitespace, subtle texture, and restrained motion. Avoid gradients, glassmorphism, stock illustrations, emoji, excessive pill-shaped cards, and repetitive equal-sized boxes.

Put the website in `public/index.html`, `public/styles.css`, and `public/app.js`. Add useful automated tests, run `npm test`, and do not finish until the page and interaction are working.
