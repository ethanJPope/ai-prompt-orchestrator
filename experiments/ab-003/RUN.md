# AB-003 run instructions

1. Make two separate, initially empty workspace folders outside `experiments/ab-003`.
2. Open a new Codex task in the first folder with AI Prompt Orchestrator v0.2 enabled.
3. Open a new Codex task in the second folder with the plugin absent or disabled before the task is created.
4. Paste `original-prompt.md` unchanged into both tasks. Do not include `rubric.md`.
5. Do not answer questions or provide corrections unless a task is genuinely blocked; record any intervention.
6. Record dispatch and completion times, then preserve both workspaces and screenshots.
7. Grade both outputs using `rubric.md` before revealing treatment assignment.

Recommended workspace names:

- `<repo-parent>\ab-003-plugin-run`
- `<repo-parent>\ab-003-baseline-run`
